# Глоссарий — PHP

---

### A

**Autoloading**
Механизм автоматической загрузки классов по требованию без явных
`require`/`include`. Стандарт PSR-4 определяет соответствие
пространства имён структуре директорий. Управляется через
Composer и его `vendor/autoload.php`.

**array_find / array_first (PHP 8.4)**
Встроенные функции поиска первого элемента, удовлетворяющего предикату: `array_find($arr, fn($v) => $v > 10)`. Заменяют ручные циклы/`array_filter` + `reset` для типового сценария «найди первый».

**Asymmetric Visibility (PHP 8.4)**
Раздельная видимость для чтения и записи: `public private(set) string $name`. Свойство читается публично, но пишется только из класса. Заменяет паттерн приватное поле + публичный getter.

---

### C

**Composer**
Менеджер зависимостей PHP. Управляет пакетами, autoloading,
скриптами сборки. `composer.json` — манифест проекта,
`composer.lock` — зафиксированные версии для воспроизводимости.

**CLI (Command Line Interface)**
Режим запуска PHP без веб-сервера. `php script.php` или через
shebang `#!/usr/bin/env php`. Используется для сборщиков,
генераторов, cron-задач. В WebForge — основной режим работы.

---

### D

**DI Container (Dependency Injection Container)**
Контейнер, управляющий созданием и внедрением зависимостей объектов.
Определяет порядок создания и списки зависимостей.
В PHP: PHP-DI, Symfony DI, Laravel Container.

**Dom\HTMLDocument (PHP 8.4)**
Новый HTML5-парсер (замена `DOMDocument`): `Dom\HTMLDocument::createFromString($html)`. Корректно обрабатывает современный HTML (теги, которые DOMDocument не понимает), поддерживает селекторы `querySelector`/`querySelectorAll`. Вместе с `Dom\HTMLList`/`Dom\HTMLCollection` — замена для парсинга веб-страниц.

---

### E

**Error Handling**
PHP имеет два механизма: старые `E_*` ошибки (trigger_error)
и современные исключения (Exception/Error). С PHP 7+ фатальные
ошибки тоже можно перехватывать через `set_error_handler` и
`register_shutdown_function`.

---

### F

**Fiber (PHP 8.1+)**
Примитив кооперативной многозадачности — легковесный поток
выполнения с явными точками приостановки (`Fiber::suspend()`).
Основа для корутин и async-библиотек (ReactPHP, Revolt).
Аналог горутин Go, но кооперативный, а не вытесняющий.

**FPM (FastCGI Process Manager)**
Менеджер PHP-процессов для продакшн веб-сервинга.
Управляет пулами процессов, их количеством, таймаутами.
Nginx + PHP-FPM — стандартная связка для PHP-сайтов.

---

### G

**Generator**
Функция с `yield`, возвращающая значения по одному без
загрузки всего набора в память. Аналог Streams в Node.js
для итерации по большим данным. Реализует `Iterator` интерфейс.

---

### I

**Interface (PHP)**
Контракт, определяющий набор методов без реализации.
Класс может реализовывать несколько интерфейсов (`implements`).
В отличие от TypeScript — номинальная типизация: класс должен
явно объявить `implements InterfaceName`.

---
### J

**JIT (Just-In-Time Compiler)** — компилятор в PHP 8+, транслирующий байткод в машинный код во время выполнения. Улучшен в PHP 8.4. Даёт прирост для CPU-интенсивных операций. Включается через `opcache.jit=tracing`.

---

### L

**Lazy Objects (PHP 8.4)**
Отложенная инициализация объектов: `ReflectionClass::newLazyGhost()`/`newLazyProxy()`. Объект создаётся без выполнения конструктора, инициализируется при первом обращении к свойству/методу. Для DI-контейнеров с дорогими зависимостями.

---

### M

**Match Expression** — структурное сопоставление в PHP 8.0+. Аналог switch, но возвращает значение и использует строгое сравнение (`===`). Не требует break.

**mb_trim / mb_ltrim / mb_rtrim (PHP 8.4)**
Мультибайтовые варианты trim: корректно обрезают пробелы и управляющие символы в UTF-8 строках. `mb_trim` также обрезает Unicode whitespace, который `trim` пропускает.

### N

**Named Arguments** — возможность PHP 8.0+ передавать аргументы по имени параметра: `function(a: 1, b: 2)`. Порядок аргументов не важен, можно пропускать опциональные.

**Namespace**
Пространство имён — механизм организации кода и предотвращения
конфликтов имён. `namespace App\Core\Parser` соответствует
директории `src/Core/Parser/` при PSR-4 autoloading.

**#[NoDiscard] (PHP 8.4)**
Атрибут: результат функции не может быть проигнорирован. Вызов `f();` без использования результата вызывает warning. Защищает от потери важных значений (ошибки, id, результаты транзакций).

**Null Coalescing (?? и ??=)**
`$value = $data['key'] ?? 'default'` — вернёт 'default' если
ключ не существует или равен null. `??=` — присваивает только
если переменная null. Аналог JavaScript `??`.

---

### O

**OPcache**
Встроенное расширение PHP, кэширующее скомпилированный байткод.
При первом запросе PHP компилирует файл → байткод сохраняется
в памяти → следующие запросы не перекомпилируют. Ускорение
production PHP в 2-5 раз. Критично правильно настроить
при деплое (сброс кэша).

---

### P

**PHP-FIG**
PHP Framework Interop Group — организация, разрабатывающая PSR
стандарты для PHP-экосистемы.

**PSR (PHP Standard Recommendation)**
Стандарты совместимости PHP-кода:
- PSR-4: Autoloading (namespace → директории)
- PSR-7: HTTP Message Interface
- PSR-11: Container Interface
- PSR-12: Extended Coding Style

**PHP_EOL**
Константа конца строки — `\n` на Unix, `\r\n` на Windows.
При генерации файлов (HTML, CSS, текст) важно использовать
явный `\n` вместо PHP_EOL для cross-platform совместимости
и предсказуемого вывода.

**Pipe Operator (PHP 8.5)**
`$value |> fn($v) => strtoupper($v)` — прокидывает результат слева как первый аргумент функции справа. Композиция преобразований без вложенных вызовов. Аналог `|>` из других языков.

**Property Hooks (PHP 8.4)**
Виртуальные свойства с хуками `get`/`set`: `public string $name { get => ucfirst($this->name); set => trim($value); }`. Валидация и трансформация при доступе без getter/setter-методов. Частично заменяет паттерн приватное поле + методы доступа.

---

### R

**Reflection API**
Встроенный PHP API для интроспекции классов, методов, свойств
и параметров в runtime. Используется DI-контейнерами,
ORM, тестовыми фреймворками. Медленнее прямых вызовов —
результаты нужно кэшировать.

---

### S

**SPL (Standard PHP Library)**
Набор встроенных структур данных и итераторов:
`SplStack`, `SplQueue`, `SplMinHeap`, `SplFileObject`,
`DirectoryIterator`, `RecursiveIteratorIterator`.
Эффективнее массивов для специфических задач.

**Static Analysis**
Анализ кода без его выполнения. Инструменты: PHPStan, Psalm.
Находят ошибки типов, необработанные nullable значения,
недостижимый код. Уровни строгости (0-9 в PHPStan).
Аналог TypeScript-компилятора для PHP.

**Stream (PHP)**
Абстракция над источниками данных в PHP: файлы, сеть, память.
`php://stdin`, `php://stdout`, `php://memory` — встроенные
потоки. `stream_get_contents()`, `fopen()` работают с любым
stream wrapper единообразно.

---

### T

**Trait**
Механизм горизонтального переиспользования кода в PHP.
Trait — это набор методов, который можно подключить в любой класс
через `use TraitName`. Решает проблему множественного наследования.
При конфликте методов нужна явная резолюция.

**Type Declarations**
Явное указание типов параметров и возвращаемых значений функций.
Включает скалярные типы (`int`, `string`, `float`, `bool`),
классы, интерфейсы, `array`, `callable`, `iterable`, `mixed`,
`never`, `void`. При `declare(strict_types=1)` — строгая проверка.

---

### U

**Union Types (PHP 8.0+)**
Параметр или возвращаемое значение может иметь несколько типов:
`function parse(string|int $id): User|null`.
До PHP 8.0 — только через PHPDoc аннотации.

---

### V

**Value Object**
Неизменяемый объект, определяемый своими значениями, а не
идентичностью. Два Value Object с одинаковыми полями — равны.
Пример: `Money`, `Email`, `CourtCode`. В PHP реализуется
через `readonly` классы (PHP 8.2) или `readonly` свойства (PHP 8.1).

---

### W

**WeakReference / WeakMap**
Ссылки, не препятствующие сборке мусора. `WeakMap` (PHP 8.0)
позволяет хранить данные, привязанные к объектам, без утечек
памяти — когда объект уничтожается, запись в WeakMap исчезает.
Полезно для кэшей в долгоживущих процессах.
