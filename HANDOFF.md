## Контекст

- «Переезд» в словаре автора = этот файл, а не перенос репозитория. Механизм
  описан в `D:\GitHub\knowledge\handoff-template.md`: коммитить и пушить, новая
  сессия читает из remote и **удаляет** файл коммитом удаления.
- Граница с диспетчером (`D:\GitHub\knowledge\session-tasks.md`): HANDOFF — только
  снимок основной сессии, задачи в нём не живут. В этом репозитории `docs/TASK.md`
  нет — он механизм для CaseCore, здесь не нужен.
- `CURRENT_*` — намеренная конвенция проекта, не плейсхолдеры и не грязь.
- Оглавления модулей не редактировать руками: они перезаписываются при сборке.
- `course.html` и `index.html` в `.gitignore` — коммитить их нельзя.
- Пять метрик модуля 12 заполнить нечем: это данные автора по стенду.
- Числа в прозе — цифрами. Смеси алфавитов внутри слова не оставлять.
- Версии сверять по официальным release notes, а не по памяти.
- Источник практики для наполнения — `D:\GitHub\CaseCore` (код, 19 ADR) и
  `D:\GitHub\knowledge` (наработки). Формат кейса в учебнике важнее красивой
  формулировки: симптом → разбор → границы → чеклист → задача AI-кодеру.
