# Глоссарий — Python

---

### A

**Annotation (аннотация типа)**
Подсказка типа для параметров и возвращаемых значений функций.
С Python 3.14 (PEP 649) аннотации вычисляются **лениво** (deferred) —
не при определении функции, а только при явном обращении.
Устраняет проблему forward references без кавычек.

**asyncio**
Стандартная библиотека для асинхронного программирования на основе
событийного цикла. Использует корутины (`async def`) и примитивы
синхронизации (`asyncio.Lock`, `asyncio.Queue`, `asyncio.Semaphore`).
Не про параллелизм — про конкурентность в одном потоке.

**async/await**
Синтаксис для определения и вызова корутин. `async def` — корутина.
`await` — приостанавливает корутину до получения результата,
не блокируя Event Loop. Только внутри `async def`.

---

### C

**Coroutine (корутина)**
Функция, объявленная через `async def`. При вызове возвращает
объект корутины, а не выполняет код. Код запускается только при
`await` или через `asyncio.run()`. Основа asyncio-модели.

**Context Manager**
Объект, реализующий `__enter__` и `__exit__` (или `__aenter__` /
`__aexit__` для async). Используется с `with` / `async with`.
Гарантирует выполнение cleanup-кода даже при исключениях.

**Comprehension**
Компактный синтаксис создания коллекций:
`[x*2 for x in range(10) if x % 2 == 0]` — list comprehension,
`{k: v for k, v in data.items()}` — dict comprehension,
`(x for x in data)` — generator expression (ленивый).

---

### D

**Dataclass**
Декоратор `@dataclass` из модуля `dataclasses`. Автогенерирует
`__init__`, `__repr__`, `__eq__` по аннотированным полям.
`@dataclass(frozen=True)` — неизменяемый объект, хэшируемый.
Аналог readonly class в PHP или readonly record в других языках.

**Decorator (декоратор Python)**
Функция, принимающая функцию и возвращающая новую функцию.
`@decorator` — синтаксический сахар для `func = decorator(func)`.
Используется для кэширования (`@functools.lru_cache`),
логирования, валидации, retry-логики.

**Dict (словарь)**
Встроенная хэш-таблица. С Python 3.7+ сохраняет порядок вставки.
С Python 3.9+ поддерживает merge operator: `a | b` и `a |= b`.
Поиск по ключу — O(1).

---

### E

**Event Loop**
Цикл событий asyncio. Управляет выполнением корутин, I/O операций,
таймеров. Одна корутина выполняется в каждый момент времени.
`asyncio.run(main())` — запустить Event Loop из синхронного кода.

---

### F

**f-string**
Строковые шаблоны с встроенными выражениями: `f"Hello, {name}!"`.
С Python 3.12 — поддержка многострочных выражений и вложенных кавычек
внутри `{}`. С Python 3.14 — добавлены **t-strings** (template strings)
как расширение f-strings для кастомных форматтеров.

**Free-threaded mode (No-GIL)**
Экспериментальный режим Python 3.13 (PEP 703), официальная поддержка
в Python 3.14 (PEP 779) — запуск без GIL. Позволяет потокам выполняться
по-настоящему параллельно на разных ядрах CPU.
Включается сборкой Python с флагом `--disable-gil`.

**Functools**
Стандартный модуль с утилитами для работы с функциями:
`functools.lru_cache` — мемоизация, `functools.partial` — частичное
применение, `functools.reduce` — свёртка, `functools.wraps` —
сохранение метаданных декорируемой функции.

---

### G

**Generator (генератор)**
Функция с `yield`, возвращающая итератор. Вычисления ленивые —
следующее значение генерируется только по запросу.
Память постоянная вне зависимости от размера данных.
Аналог Generator в Node.js или PHP.

**GIL (Global Interpreter Lock)**
Мьютекс в CPython, позволяющий только одному потоку выполнять
Python-байткод в каждый момент. Делает многопоточность неэффективной
для CPU-задач. Обходится через `multiprocessing` или в free-threaded
build Python 3.13+.

---

### I

**Iterator Protocol**
Объект, реализующий `__iter__()` и `__next__()`. `__iter__`
возвращает сам объект, `__next__` возвращает следующее значение
или бросает `StopIteration`. Основа всех циклов `for` в Python.

---

### L

**Lambda**
Анонимная функция с одним выражением: `lambda x: x * 2`.
Ограничена — нет многострочного тела, нет инструкций.
Используется для коротких callback-функций в `map`, `filter`, `sorted`.

**List**
Изменяемая упорядоченная коллекция. Поддерживает срезы (`a[1:3]`),
отрицательные индексы (`a[-1]`). Добавление в конец — O(1)
амортизированно. Вставка в начало — O(n). Не используй как очередь
— используй `collections.deque`.

---

### M

**Match/Case** — структурное сопоставление в Python 3.10+. Позволяет деструктурировать dict, list, tuple и классы в условиях. Мощнее switch: поддерживает guards (`if`), распаковку, literals.

**Metaclass**
Класс классов — определяет поведение при создании нового класса.
`type` — стандартная метаклассовая фабрика. Используется
в ORMах (Django, SQLAlchemy) для магии декларативных моделей.
Инструмент для фреймворков, не для бизнес-кода.

**Multiprocessing**
Стандартный модуль для запуска кода в отдельных OS-процессах.
Каждый процесс — отдельный Python интерпретатор с отдельной памятью.
Обходит GIL. Данные передаются через `Queue`, `Pipe` или
shared memory (`multiprocessing.shared_memory`).

**Mypy** — статический анализатор типов для Python. Проверяет аннотации без выполнения кода. Запуск: `mypy --strict src/`. Альтернатива: pyright (быстрее), basedpyright (строже).

---

### P

**Pydantic**
Библиотека для валидации данных и управления настройками через
аннотации типов. `BaseModel` — базовый класс для валидируемых
объектов. Используется в FastAPI как основа схем запросов/ответов.
Аналог Zod в TypeScript-экосистеме.

**Protocol**
Механизм структурной типизации (PEP 544). Класс, унаследованный от
`typing.Protocol`, задаёт набор методов. Любой класс, реализующий
эти методы, считается совместимым — без явного `implements`.
Аналог интерфейсов TypeScript.

---

### S

**Slot (`__slots__`)**
Явное определение допустимых атрибутов объекта вместо динамического
`__dict__`. Снижает потребление памяти (~40-60%) и ускоряет
доступ к атрибутам. Полезно для объектов, создаваемых миллионами
(строки данных, точки координат).

**Sub-interpreter (подинтерпретатор)**
Изолированный экземпляр Python-интерпретатора в рамках одного процесса.
Python 3.14 (PEP 734) добавил официальный stdlib API (`interpreters`).
Позволяет настоящий параллелизм без отдельных OS-процессов.
Данные передаются через `interpreters.Channel`.

---

### T

**T-string (Template String)**
Новый тип строк в Python 3.14 (PEP 750): `t"Hello, {name}!"`.
В отличие от f-strings, не производит строку немедленно —
возвращает объект `Template`, который можно передать
в кастомный форматтер. Позволяет безопасную обработку
(SQL-инъекции, HTML-экранирование) на уровне синтаксиса.

**Type Alias**
Псевдоним типа. С Python 3.12: `type Vector = list[float]`.
Ключевое слово `type` делает alias явным и проверяемым.
Отличие от `Vector = list[float]` — последнее создаёт обычную
переменную, не алиас типа.

**TypeVar**
Переменная типа для обобщённых функций и классов.
`T = TypeVar('T')` — неограниченный, `T = TypeVar('T', bound=int)` —
ограниченный. С Python 3.12 — новый синтаксис:
`def first[T](lst: list[T]) -> T`.

---

### U

**UV**
Современный быстрый пакетный менеджер и инструмент управления
виртуальными окружениями для Python, написанный на Rust.
Замена `pip` + `venv` + `pyenv`. Установка пакетов в 10-100x
быстрее pip. Управляет версиями Python без pyenv.
Де-факто стандарт в новых проектах 2025+.

---

### V

**Virtual Environment (venv)**
Изолированное Python-окружение с собственным набором пакетов.
Создаётся через `python -m venv .venv` или `uv venv`.
Позволяет иметь разные версии пакетов для разных проектов.

---

### W

**walrus operator (`:=`)**
Оператор присваивания в выражении (Python 3.8+).
`if (n := len(data)) > 10: print(n)` — присваивает и проверяет.
Полезен в `while` циклах и list comprehensions.
Не злоупотребляй — читаемость страдает при сложных выражениях.

---

### Y

**yield / yield from**
`yield` — приостанавливает генератор и возвращает значение.
`yield from` — делегирует итерацию другому генератору или итерируемому.
В asyncio — внутренняя основа `await` (корутины исторически
строились на генераторах через `yield from`).
