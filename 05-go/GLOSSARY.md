# Глоссарий — Go

---

### B

**Benchmark**
Функция вида `func BenchmarkXxx(b *testing.B)` в `_test.go` файле.
Запускается через `go test -bench=.`. `b.N` — количество итераций,
определяется автоматически. Встроен в toolchain — никаких
внешних зависимостей.

**Build Tags (Build Constraints)**
Директивы `//go:build` в начале файла для условной компиляции.
`//go:build linux && amd64` — файл включается только на Linux x86-64.
Используется для платформо-специфичного кода, тестовых помощников,
флагов сборки.

---

### C

**Channel**
Типизированный канал для передачи данных между горутинами.
`make(chan int)` — небуферизованный (блокирует до получателя),
`make(chan int, 100)` — буферизованный (блокирует при полном буфере).
Философия: *«Don't communicate by sharing memory;
share memory by communicating»*.

**Context (context.Context)**
Стандартный механизм для распространения: дедлайнов,
таймаутов, сигналов отмены и пользовательских значений через
дерево вызовов. `context.WithCancel`, `context.WithTimeout`,
`context.WithDeadline`. Первый аргумент каждой I/O функции в Go.

**cgo**
Механизм вызова C-кода из Go. Позволяет использовать нативные C-библиотеки.
Серьёзные ограничения: замедляет сборку, усложняет кросс-компиляцию,
отключает некоторые оптимизации. Используй только когда нет альтернативы.

---

### D

**defer**
Откладывает выполнение функции до возврата из текущей функции.
Выполняется в порядке LIFO. Гарантирует cleanup даже при панике.
`defer file.Close()` сразу после `Open()` — стандартный идиом.
С Go 1.21 — оптимизирован, почти без overhead.

**defer + recover**
Единственный способ поймать панику в Go:
```go
defer func() {
  if r := recover(); r != nil {
    log.Printf("recovered: %v", r)
  }
}()
```
Использовать только на границах пакетов или горутин.
Внутри пакета — возвращать ошибки, не паниковать.

---

### E

**Embedding (встраивание)**
Включение одного типа в другой без явного поля:
```go
type Logger struct{ *log.Logger }
```
Все методы `log.Logger` доступны на `Logger` напрямую.
Это **не** наследование — это делегирование.
Нет иерархий классов, нет `super`, нет ромбовидного наследования.

**Error (ошибка в Go)**
Встроенный интерфейс `error` с одним методом `Error() string`.
Ошибки — это обычные значения, не исключения. Возвращаются
явно как последнее возвращаемое значение функции.
`errors.Is` — проверить тип/значение в цепочке, `errors.As` — извлечь.

**errors.Join (Go 1.20+)**
Объединение нескольких ошибок в одну:
```go
err := errors.Join(err1, err2, err3)
```
Работает с `errors.Is` и `errors.As` для каждой из объединённых ошибок.
В Go 1.24 улучшена эффективность.

### G

**Garbage Collector (GC)** — трёхцветный concurrent mark-and-sweep GC в Go. Минимизирует STW-паузы (~100μs). Настраивается через GOGC (порог роста кучи) и GOMEMLIMIT (жёсткий лимит).

**Generics** — параметризованные типы в Go 1.18+. Позволяют писать функции и типы с произвольным типом: `func Fn[T any](arg T) T`. Go 1.24 добавил generic type aliases.

**Goroutine**
Легковесный поток управляемый Go runtime. Стартовый стек ~2KB
(против ~1MB у OS-потоков). Runtime мультиплексирует тысячи горутин
на небольшое число OS-потоков. `go func()` — запустить горутину.
Стоимость создания настолько мала, что одна горутина на запрос —
стандартная архитектура.

**GOMAXPROCS**
Переменная окружения и `runtime.GOMAXPROCS(n)` — количество
OS-потоков для параллельного выполнения горутин.
По умолчанию = количеству логических CPU. Настраивается
в контейнерных окружениях через `GOMAXPROCS=N`.

**go.mod**
Файл модуля — определяет имя модуля и минимальные версии зависимостей.
Аналог `package.json`. `go.sum` — криптографические хэши для
верификации зависимостей. Вместе гарантируют воспроизводимые сборки.

---

### I

**Interface**
Набор методов, неявно реализуемый любым типом. Структурная
типизация — нет ключевого слова `implements`. Маленькие интерфейсы
лучше больших: `io.Reader` (1 метод), `io.Writer` (1 метод),
`io.Closer` (1 метод). Философия Go: *«Accept interfaces, return structs»*.

**Iterator (range-over-func, Go 1.23)**
Go 1.23 добавил `range` по функциям-итераторам:
```go
func Pairs[K, V any](m map[K]V) iter.Seq2[K, V]

for k, v := range Pairs(myMap) {
  fmt.Println(k, v)
}
```
Стандартный пакет `iter` с типами `Seq[V]` и `Seq2[K, V]`.
Унифицирует работу со всеми последовательностями.

---

### M

**Map**
Встроенная хэш-таблица. С Go 1.24 — новая реализация на основе
Swiss Tables: быстрее итерация и поиск, меньше памяти.
Не потокобезопасна — для конкурентного доступа используй `sync.Map`
или мьютекс. Нулевое значение — `nil`, запись в nil map — паника.

**Module**
Единица дистрибуции и версионирования Go-кода. Набор пакетов
с общим `go.mod`. Семантическое версионирование: модули v2+
должны иметь `/v2` суффикс в пути импорта.

**Mutex (sync.Mutex)**
Мьютекс для защиты разделяемых данных.
`mu.Lock()` / `mu.Unlock()` или `defer mu.Unlock()`.
`sync.RWMutex` — для сценариев «много читателей, один писатель».
Встроен в `sync` — без внешних зависимостей.

---

### P

**Panic**
Аналог неперехваченного исключения. Вызывает раскрутку стека
и завершение горутины (и всего процесса если не перехвачен).
Легитимен для: инициализационных ошибок, нарушения инвариантов,
ошибок программиста (не пользователя). В бизнес-логике — не использовать.

**Profile (pprof)**
Встроенный профилировщик. `net/http/pprof` — HTTP эндпоинт для
CPU, memory, goroutine профилей. `go tool pprof` — анализ.
Без внешних зависимостей. Запускается в production не нагружая систему.

---

### R

**Race Condition (гонка данных)**
Одновременный доступ к переменной из нескольких горутин
без синхронизации. Обнаруживается встроенным детектором:
`go test -race` или `go run -race`. В production — серьёзная ошибка,
поведение непредсказуемо.

---

### S

**Select**
Множественный выбор по каналам — как `switch` но для операций с
каналами. Блокирует до готовности одного из case.
`default` case — неблокирующий select. Основа timeout-паттернов:
```go
select {
case res := <-ch:   // данные пришли
case <-ctx.Done():  // отменено/таймаут
}
```

**Slice**
Заголовок `{pointer, length, capacity}` над массивом. Не копирует
данные при передаче в функции — передаётся заголовок.
`append()` может создать новый массив если capacity исчерпан.
Срез среза (`s[1:3]`) — разделяет память с оригиналом.

**Struct Tags** — строковые метаданные к полям struct в Go. Используются для сериализации (json, xml), валидации, ORM. Формат: `Field type `json:"field_name,omitempty"`. Пробелы в tag — частый источник багов.

**sync.Once**
Гарантирует однократное выполнение функции при конкурентных вызовах.
Идиом для ленивой инициализации синглтонов:
```go
var once sync.Once
once.Do(func() { /* выполнится ровно один раз */ })
```

---

### T

**Table-driven Tests**
Стандартный паттерн тестирования в Go:
```go
tests := []struct{ input string; want int }{ ... }
for _, tt := range tests {
  t.Run(tt.input, func(t *testing.T) { ... })
}
```
Встроен в `testing` — никаких фреймворков не нужно.

**toolchain (Go 1.21+)**
Директива в `go.mod`, фиксирующая конкретную версию Go-компилятора:
```
go 1.24
toolchain go1.24.1
```
Гарантирует что все разработчики используют идентичный компилятор.

---

### U

**unsafe**
Пакет, открывающий доступ к низкоуровневым операциям: арифметика
указателей, прямая работа с памятью, обход системы типов.
`unsafe.Pointer` — конвертация между несовместимыми типами указателей.
Используй только с документированным обоснованием и тестами.

---

### V

**Variadic Function**
Функция с переменным количеством аргументов: `func sum(nums ...int)`.
Внутри `nums` — обычный slice. Вызов: `sum(1, 2, 3)` или
`sum(slice...)` для spread. `fmt.Printf`, `append` — примеры.

---

### W

**WaitGroup (sync.WaitGroup)**
Примитив ожидания завершения группы горутин.
`wg.Add(n)` — добавить счётчик, `wg.Done()` — уменьшить,
`wg.Wait()` — блокировать до нуля. Стандартный паттерн
параллельной обработки без каналов.

---

### Z

**Zero Value**
Каждый тип в Go имеет нулевое значение без явной инициализации:
`0` для числовых, `""` для строк, `false` для bool, `nil` для
указателей/слайсов/map/каналов/функций. Это не null — zero value
часто является полностью рабочим значением. `sync.Mutex{}` — рабочий
мьютекс без инициализации.
