# GLOSSARY — Desktop-приложения: Go + WebView

## B

**Bind**
Механизм моста JS→Go в webview_go: `w.Bind("name", fn)`. Биндит ТОЛЬКО функции, не структуры. В JS имя становится глобальной функцией.

---

## C

**Code Signing**
Электронная подпись бинарника (Authenticode). Долгосрочное решение против антивирусных срабатываний и предупреждений SmartScreen при поставке.

**CREATE_NO_WINDOW**
Флаг создания процесса (0x08000000) для console-процессов из GUI-приложения. Без него Windows создаёт новую консоль — чёрное окно мигает при каждом запуске.

---

## E

**Eval**
Механизм моста Go→JS: `w.Eval("document.title = 'x'")` — выполняет JS в контексте страницы. Не работает для `document.title` на Windows-реализации (заголовок окна не обновляется).

---

## L

**Loopback HTTP-сервер**
Встроенный `http.Server` на `127.0.0.1:0` внутри приложения. UI отдаётся через `Navigate` на этот адрес. Рендерится надёжнее `SetHtml` и тестируется как обычные HTTP-эндпоинты.

---

## P

**Profile**
Конфигурация пользователя в `~/.config/<app>/profile.json`: API-URL, модель, температура, темы. Вне репо и бинарника. Поля экранируются при интерполяции в HTML/JS.

---

## S

**SetHtml**
`w.SetHtml(html)` → `NavigateToString`. До готовности контрола WebView2 даёт тёмный фон без контента. Не использовать для стартовых/служебных страниц.

---

## T

**TDZ (Temporal Dead Zone)**
Ситуация, когда локальная JS-переменная объявлена после использования (`const hasKey = await hasKey()`). При коллизии имени с биндингом — ReferenceError. Префиксуй локальные имена.

---

## W

**WebView2**
Системный движок рендеринга Windows (Edge Chromium). Встроен в Win10/11. Не полноценный браузер: нет расширений, разное поведение между платформами.

**WebKitGTK**
Системный движок Linux (`libwebkit2gtk-4.0`). Обычно предустановлен.

**WKWebView**
Системный движок macOS. Встроен.

**webview_go**
Go bindings для webview (C library). Биндит только функции, бинарник ~6 MB.
